# SnapCal Web core — module map & UI contract

- `nutrition.js` — pure math. `mifflinStJeorBMR(w,h,age,sex)`, `tdee(bmr,activity)`, `targetCalories(tdee,delta)`, `macroTargets(cals)->{proteinG,carbsG,fatG}`, `resolveUserGoals(profile)->{bmr,tdee,computedTargetCalories,targetCalories,proteinTargetG,carbsTargetG,fatTargetG,hasValidStats}`, `computeStreak(loggedDayTimestamps,today?)`, `startOfDay(date)`, `roundDisplay(n)`.
- `store.js` — localStorage CRUD + pub/sub. `subscribe(fn)->unsub`. FoodEntry: `addFoodEntry(fields)`, `updateFoodEntry(id,patch)`, `deleteFoodEntry(id)`, `getFoodEntry(id)`, `allFoodEntries()`, `entriesForDay(date?)`, `totalsForDay(date?)`, `recentlyUploaded(limit=10)`, `historyGroupedByDay()`, `weekStrip(date?)`, `streak(date?)`. Water: `getWaterEntryForDay(date?)`, `incrementWater(date?)`, `decrementWater(date?)`. Profile: `getProfile()`, `setProfile(patch)`, `computeGoals()`. Saved foods: `allSavedFoods()`, `addSavedFood({name,calories,proteinG,carbsG,fatG,source})`, `deleteSavedFood(id)`, `logSavedFood(id)`. Flags: `isNotifyBannerDismissed()`, `setNotifyBannerDismissed(bool)`.
- `resize.js` — `resizeImage(blobOrFile,{maxEdge=768,quality=0.8})->Promise<{blob,dataUrl,width,height}>`, `resizeDataUrl(dataUrl,opts)`, `computeTargetSize(w,h,maxEdge)`.
- `api.js` — `offLookupBarcode(barcode)`, `offSearchByName(query)`, `usdaLookupBarcode(barcode)`, `foodLookup(barcode)` (OFF→USDA chain, returns `{status:"found"|"notFound"|"failed",product?,message?}`), `groundItems(items,{budgetMs?})`, `analyzeWithGemini({mode,imageDataUrl?,text?})` (raw server call), `analyzeMeal({mode,imageDataUrl?,text?})->Promise<{success:true,items}|{success:false,reason}>` — **the one function the UI should call to run AI analysis**, `ANALYSIS_MODES` (meal/label/text metadata: `requiresImage`,`groundsAgainstUSDA`,`pendingTitle`,`pendingRampSeconds`).
- `queue.js` — `enqueuePhoto(imageDataUrl,mode,{description?})->FoodEntry`, `enqueueText(description)->FoodEntry|null`, `canRetry(entry)`, `retry(entryId)`, `submitCorrection(entryId,text)->Promise<outcome>`, `sweepIfNeeded()` (call once at startup, before rendering), `onComplete(fn)->unsub`, `entryState(entry)->"pending"|"failed"|"completedWithItems"|"completedPlain"`, `requestNotificationPermission()`, `isNotificationAuthorized()`.
- `api/gemini.js` — POST `/api/gemini` `{mode,image?,text?}` → `{items}` or `{errorType,message}`. Never called directly by UI; use `analyzeMeal`.

UI re-renders on `store.subscribe(fn)`. Call `queue.sweepIfNeeded()` once on app boot.
